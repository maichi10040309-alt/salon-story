# Salon Story - わたしのサロン経営

美容サロンを育てる、ブラウザ対応の2D経営・接客シミュレーションゲームです。

## Ver.0.4

- 直近7日・最終来店日・未遭遇・顧客ランク・予約・トレンドを使う重み付き来店抽選
- 通常客の翌日連続来店を抑止、Day 1〜7の未遭遇客保証、予約と飛び込みの分離
- 来店理由表示、曜日、予約一覧、NEWS、主人公Energy、休息日
- 主要顧客10名の全5段階キャラクターStory
- スタッフプロフィール、仲良し度イベント、5段階役職、スキル、指名・人気
- 5施設の2D街マップ（Salon / Fashion / Beauty / Cafe / Training School）
- 44点のパーツ服、4ブランド、ブランド好感度、STYLE評価
- 髪型20種、メイク6種、パーツ別コーデの接客補正
- 3エリアから選ぶ2号店、店長任命、自動営業、店舗別売上
- ライバルオーナー3名、サロンコンテスト
- Ver.0.1〜0.3セーブデータの自動移行

## Ver.0.3

- 顧客32名、進行条件によるアンロック、未遭遇シルエット、顧客コレクション
- 店舗Rank D〜A、条件判定、費用を払う店舗拡張、Rank別の店舗表示
- Chapter 1〜5、達成報酬、3つのライバルサロンと人気ランキング
- 主人公名・肌色・髪型8種・髪色6種を保存できる簡易アバター
- 衣装6種の購入・着替えと顧客別の接客ボーナス
- 美容機器5種の購入・Lv.3までの強化・施術効果
- デイリーミッション3件、日替わり美容トレンド、営業結果への反映
- Ver.0.1 / Ver.0.2セーブデータを保持するマイグレーション

## Ver.0.2から継続

- 顧客10名それぞれに専用カウンセリング4択とリアクション
- PERFECT / GOOD / OK / NOT BAD / BAD評価
- 信頼度・次回来店率・人気・XPのビフォーアフター表示
- 顧客カルテ、顧客ランク、口コミ履歴
- Salon Lv.1〜5とメニューアンロック・開発・強化
- スタッフLv・経験値・体力
- 短期経営目標と達成報酬
- 簡易2D店舗と来店・施術演出
- Ver.0.1セーブデータの自動移行

## Ver.0.1から継続

- 営業開始 → カウンセリング → 施術提案 → 満足度・売上計算 → 口コミ・リピート判定 → 日次結果
- 初期スタッフ3名からの採用、4種類の研修
- 施術、顧客データを独立したデータモジュールで管理
- 広告、設備購入、顧客一覧、経営グラフ
- localStorageによる自動セーブ
- PC・スマートフォン対応
