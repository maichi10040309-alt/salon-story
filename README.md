# Salon Story - わたしのサロン経営

美容サロンを育てる、ブラウザ対応の2D経営・接客シミュレーションゲームです。

## Ver.0.1

- 営業開始 → カウンセリング → 施術提案 → 満足度・売上計算 → 口コミ・リピート判定 → 日次結果
- 初期スタッフ3名からの採用、4種類の研修
- 5種類の施術、10名の顧客データ
- 広告、設備購入、顧客一覧、経営グラフ
- localStorageによる自動セーブ
- PC・スマートフォン対応

## 起動

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
